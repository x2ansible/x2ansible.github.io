# Documentation versions

| Version | Status | Documentation | Deployment manifests |
| --- | --- | --- | --- |
| Latest | Current | [Read latest](latest/) | [`deploy/`](https://github.com/x2ansible/x2ansible.github.io/tree/main/deploy) |

A frozen version is never updated with current instructions. When a new release is published, copy `docs/latest/` and `deploy/` into new version directories and update the version index.

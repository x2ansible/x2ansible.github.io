# Advanced Features

Capabilities that go beyond the core migration workflow.

### [Organizational Rules]({% link v0.5/advanced/rules.md %})
Inject organization-specific guidance into the migration agents.

### [Human Checkpoints]({% link v0.5/advanced/human-checkpoints.md %})
Review points and decision gates at each migration phase.

### [Telemetry]({% link v0.5/advanced/telemetry.md %})
Migration metrics, cost tracking, and reporting.

### [Adversarial Agents]({% link v0.5/advanced/adversarial-agents.md %})
Read-only AI reviewers that inspect migration artifacts for security gaps and correctness issues.
